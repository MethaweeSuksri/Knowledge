#meta

> A quick cheat sheet for the most common Obsidian Markdown syntax, links, tags, and shortcuts.

## Markdown

```markdown
# Heading
**Bold**
*Italic*
~~Strikethrough~~
==Highlight==

- Bullet
1. Numbered
- [ ] Todo
- [x] Done
> Quote
`Code`
```

## Link

Connects one note to another.

```markdown
[[My Note]]
```

## Tag

Labels or categorizes a note so you can find related notes.

```markdown
#study
#project
```

## Callout

A highlighted box for important information, tips, warnings, etc.

```markdown
> [!NOTE]
> Important info
```

## Properties

Information about the note itself, such as status, tags, dates, or categories.

```yaml
---
status: active
tags: [study]
---
```

## Images / Files

```markdown
![[image.png]]
![[Note Name]]
```

## Shortcuts

- `Ctrl/Cmd + P` → Command palette
- `Ctrl/Cmd + O` → Open note
- `Ctrl/Cmd + N` → New note
- `Ctrl/Cmd + F` → Find
- `Ctrl/Cmd + E` → Edit/Reading view

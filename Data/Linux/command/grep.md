# What does grep do

search for pattern in file -> print Matched line

grep with no flag read from stdin
grep with -r argumenat seach the entire direcrtory


| flag        | does                              |
| ----------- | --------------------------------- |
| **NO FLAG** | read from stdin                   |
| **i**       | case insensetive                  |
| **o**       | print match only (not whole line) |
